## 在 ChatGPT 端测试

先在目标 ChatGPT 账号中连接 GitHub，并确保连接获准访问 `Jae00214/leo-stickers`。当前 Codex 聊天的连接成功不代表另一个 ChatGPT 聊天自动具备相同工具与权限。

将下列提示词粘贴到目标聊天：

## 私有链接的含义

索引中 `url` 是登录后可查看的 GitHub 文件页面，`url_type` 为 `github_authenticated_file`，不是可直接内嵌的公开图片直链。
`retrieval` 提供 repository、ref、path，供授权工具读取实际文件。不要把 GitHub 页面 URL 当成 PNG URL。
私有仓库不能使用匿名 GitHub Raw 或 jsDelivr CDN 来读取图片。本索引不保存 Token、临时授权链接或其他凭据。
仅粘贴仓库网址，不会赋予 ChatGPT 访问权限；能读文本的 GitHub 工具也不一定支持图片显示，须实际验证。

## 如何新增

1. 上传图片到 `stickers/`；复古猫未来按 [分类方案](docs/vintage-cat-sources.md) 命名。
2. 添加唯一编号、中文描述名、情绪标签、聊天场景、真实画面描述及文件路径。
3. 根据当前条目填写 url_type 与 retrieval；记录实际来源和许可，不把第三方角色图片标为 MIT。
4. 提交后通过授权工具回读索引与图片，测试选图及显示。
5. 同一张图只存一份，用多个标签覆盖不同场景。无明确原名时使用描述名，不编造官方名称。
